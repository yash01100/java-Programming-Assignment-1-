## 📌 Project Overview

This project is a simple **Banking Application** developed in Java that allows users to:

- Create a bank account  
- Deposit money  
- Withdraw money  
- View account details  
- Update contact details  

The project demonstrates the usage of **Java classes, objects, control structures, arrays, strings, and input handling** as per the course syllabus.

---

## 🎯 Objectives

- Implement Java fundamentals: data types, operators, type casting  
- Use loops and decision-making statements  
- Work with the `Scanner` class for input  
- Manage multiple accounts using arrays  
- Apply OOP principles such as encapsulation and modularity  
- Handle and validate strings (names, email, phone number)
